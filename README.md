# Google Cybersecurity Professional Certificate - Portfolio

Questo repository contiene la documentazione pratica e i progetti sviluppati durante il conseguimento del Google Cybersecurity Professional Certificate. L'obiettivo è dimostrare competenze operative nell'analisi delle minacce, nella risposta agli incidenti e nella gestione della sicurezza dei sistemi.

## 🛡️ Domini di Competenza e Progetti

| Ambito Operativo | Descrizione dell'Attività | Strumenti Utilizzati | Link alla Prova |
| :--- | :--- | :--- | :--- |
| **Analisi Traffico di Rete** | Identificazione di vettori di attacco e anomalie tramite l'ispezione approfondita dei pacchetti TCP/HTTP. | Wireshark, tcpdump | [Vedi log di rete](./Network_Security_and_Traffic_Analysis/) |
| **Incident Response** | Documentazione e analisi post-incidente per il contenimento delle minacce. Applicazione pratica del framework NIST. | Modelli di Reportistica | [Vedi Report Incidenti](./Incident_Response_and_Reporting/) |
| **Risk Assessment** | Valutazione delle vulnerabilità architetturali e pianificazione di strategie di mitigazione dei rischi. | Matrici di Rischio | [Vedi Valutazione](./Risk_Assessment_and_Hardening/) |
| **Identity & Access Management** | Messa in sicurezza degli asset aziendali tramite gestione avanzata dei permessi utente (chmod/chown) e autorizzazioni. | Bash, Linux CLI | [Vedi Script Linux](./Linux_and_Asset_Management/) |
| **Automazione Sicurezza** | Sviluppo di script per automatizzare il parsing dei log e l'aggiornamento dinamico delle allow-list degli indirizzi IP. | Python | [Vedi Codice Python](./Python_Automation/) |

## 🚀 Competenze Tecniche Acquisite

* **Security Operations (SecOps):** Monitoraggio continuo, rilevamento delle minacce e applicazione del ciclo di vita della risposta agli incidenti.
* **Network Security:** Comprensione dei protocolli di rete (TCP/IP, DNS, HTTP) e capacità di isolare traffico malevolo.
* **Linux & Automation:** Navigazione da riga di comando, gestione dei privilegi di sistema e automazione di task ripetitivi tramite Python.
* **Security Frameworks:** Familiarità con i principi guida del NIST Cybersecurity Framework (Identify, Protect, Detect, Respond, Recover).
